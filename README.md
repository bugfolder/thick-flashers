# Thick Flashers

A _Mathematica™_ package for constructing thick flashers.

This _Mathematica™_ notebook is supplemental material for the paper "Efficiently Stowed Flashers with Uniform-Thickness Panels Based on Non-Developable Origami," by Robert J. Lang, Davis Wing, Spencer P. Magleby, and Larry L. Howell, published in the _ASME Journal of Mechanisms and Robotics_ in 2026.

It is based on Robert J. Lang's [_Tessellatica_ package for origami design](https://langorigami.com/article/tessellatica/).
